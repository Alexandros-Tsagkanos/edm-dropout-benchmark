# Data availability

This repository follows the redistribution terms of every dataset it touches. Datasets that
are openly licensed for redistribution are **bundled**; datasets that are not are **referenced**
(source URL + SHA-256 + how to obtain), with a provenance note kept in their folder. This mirrors
the guidance the project wrote for itself in the per-folder `provenance_*.md` / `REDISTRIBUTION_NOTE.md`.

When you use a dataset, cite its originators (see `docs/anchor_papers.md` → *Datasets*).

## Not redistributed here (and why)

- **The four MDPI anchor PDFs** — copyrighted by the publisher. Cited with DOIs in
  `docs/anchor_papers.md`.
- **`Stanford.csv` and the extracted Stanford corpus** — third-party data under its own terms;
  the project's own `REDISTRIBUTION_NOTE.md` instructs linking rather than bundling. Provenance
  (source URL, SHA-256, derivation chain) is kept so the test set is reconstructable and the
  committed outputs under `RESULTS/forum_urgency/` remain inspectable.
- **The Tecnológico Data Descriptor PDF + dictionary teaser, and the TRIAD/SentiDrop arXiv PDFs**
  — third-party documents; cited by DOI / arXiv id instead.

## Reproducibility

Every committed number is regenerated by the code as documented in `RESULTS/REPRODUCE.md`.
All randomness is seeded (`RANDOM_SEED=42`); deterministic components reproduce exactly, while
the neural components can drift by a few thousandths across `torch`/`xgboost` versions — which is
why the headline claims rest on the ten-seed studies (mean ± std + paired Wilcoxon), not any
single run. The provenance notes record SHA-256 hashes for the externally sourced files.
